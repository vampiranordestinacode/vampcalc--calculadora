# 🦇 VampCalc

Uma calculadora temática inspirada no universo gótico, desenvolvida como projeto de estudo utilizando HTML, CSS e JavaScript.

##  Sobre o projeto

O objetivo deste projeto é desenvolver uma calculadora funcional com uma interface personalizada, utilizando uma mascote chamada **Vampi**, uma pequena vampira que acompanha a aplicação. Além de realizar operações matemáticas básicas, o projeto busca proporcionar uma experiência visual agradável e intuitiva, unindo programação, design e interatividade.

A calculadora foi desenvolvida com as tecnologias **HTML**, **CSS** e **JavaScript**, permitindo que o usuário realize cálculos de forma simples e eficiente. Durante o desenvolvimento, foram aplicados conceitos de estruturação de páginas, estilização de interfaces, manipulação do DOM, eventos de clique, lógica de programação e tratamento de entradas do usuário.

Também foram implementadas funções extras para tornar a calculadora mais completa, como o cálculo de **porcentagem (%)**, que permite obter resultados de forma rápida e prática, e o botão **±**, responsável por alternar o sinal do número entre positivo e negativo. Essa funcionalidade facilita a realização de operações que envolvem números negativos, sem a necessidade de apagar e digitar o valor novamente.

A presença da mascote Vampi torna a aplicação mais divertida e original, reforçando a identidade visual do projeto e demonstrando como elementos gráficos podem melhorar a experiência do usuário. Dessa forma, este projeto serve como prática dos principais fundamentos do desenvolvimento web, ao mesmo tempo em que apresenta uma interface criativa, funcional e de fácil utilização.
